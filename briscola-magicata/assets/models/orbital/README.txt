ORBITAL ARENA MODELS
====================
22 GLB files:
- 4 Drone
- 4 Shield
- 4 Virus
- 4 Radiation
- 4 Magicata
- 2 Citadels built on asteroids
Lasers are intentionally excluded.

All assets are procedural low-poly game props. Materials are embedded in the GLB.
The models are independent files so a game can load/cache only the family or object needed.
See manifest.json for programmatic names.
